\section{Methods}
	\subsection{Iterations}
	For this project SCRUM tactics has been used with an attempt to keep each iteration within 2 weeks and analyse the state of the project after each iteration. This was done because of the belief that this would give the best overview of this project and best allow for required change of requirements. The first day of each iteration will be used for writing, taking notes of thoughts about previous iteration. Updates will be made on the class diagram to support the overview of the project. A good overview of the system allows for the development to question some of the ways which some of the features have been implemented on the system which supports the developer to take action and change the implementation before it becomes a problem.
	\subsection{Tools}
	Usage of tools that allows to see the memory and CPU usage can help to discover problems or bottlenecks early. I will also develop/use tools to speed up testing and experimentation. I developed a \gls{gui} to speed up testing so I can have a varied set of cases easily deployable. I make use of docker for deployment of the experiments, docker will also allow me to record CPU, memory and network usage.
